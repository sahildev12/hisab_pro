Create a modern, fast, mobile-friendly calculation app called **HisabPro**.

### App Purpose

HisabPro is a simple calculation tool for entering multiple rows containing an amount and a bracket/passing number, automatically calculating the totals and final amount, and generating a ready-to-copy WhatsApp-style message.

The most important requirement is **100% accurate arithmetic**. Every calculation must be performed programmatically, never manually or approximately.

### Calculation Logic

For every row, the user enters:

**Amount** = the main amount.

**Bracket** = the number used for the passing calculation.

Calculate:

**TOTAL AMOUNT = SUM(all Amount values)**

**TOTAL BRACKET = SUM(all Bracket values)**

Then calculate:

**PASSING AMOUNT = TOTAL BRACKET × 96**

Then:

**LENE AAJ = TOTAL AMOUNT − PASSING AMOUNT**

Important:

* Do NOT subtract the bracket from the amount.
* Do NOT apply 96% to the total amount.
* The 96 multiplier is applied specifically to the TOTAL BRACKET.
* Preserve decimal values accurately.
* Recalculate everything whenever data changes.
* Show the calculation breakdown so the user can verify it.

### Example

For the provided data:

TOTAL AMOUNT = 120,777

TOTAL BRACKET = 1,059.5

PASSING = 1,059.5 × 96 = 101,712

LENE AAJ = 120,777 − 101,712 = **19,065**

The app must show **₹19,065** as the final result.

### Important Validation

Before calculating:

* Amount must be a valid number.
* Bracket must be a valid number.
* Empty rows should either be ignored or clearly flagged.
* Support commas in entered amounts, e.g. 12,077.
* Support decimals.
* Never produce NaN, undefined, Infinity, or incorrect totals.
* Display a clear validation error if an invalid number is entered.
